## 一、属性克制

- 18 种属性：普通、草、火、水、光、地、冰、龙、电、幻、毒、虫、翼、恶、萌、幽灵、武、机械

## 二、精灵属性

### 2.1 基础
- 6 项种族值：HP、物攻(ATK)、物防(DEF)、魔攻(SPA)、魔防(SPD)、速度(SPE)
- 1-2 个属性（主属性 + 可选副属性）
- 特性文本（如"最好的伙伴：造成克制伤害后,获得攻防速+20%,并回复2能量"）

### 2.2 实际属性计算公式 ✅

```
个体值范围: 0-100，默认 50
性格倍率: 1.1 / 1.0 / 0.9

HP  = round((种族HP × 1.7 + 个体值 × 0.85 + 70) × 性格倍率 + 100)
其他 = round((种族值 × 1.1 + 个体值 × 0.55 + 10) × 性格倍率 + 50)
```

> ⚠️ 注意：此公式为 PVP 中使用的基础公式。培养（星级/觉醒）对属性的数值影响仍在确认中。

### 2.4 天分（个体值）🔍

每只精灵随机获得 **1~3 条**个体值加成：

| 天分等级 | 加成条数 | 每条加成 |
|----------|:--------:|:--------:|
| 一般般 | 1 | +7~10 |
| 还不错 | 2 | +7~10 |
| 相当好 | 3 | +7~10 |

- "了不起"必须有一条与性格增幅项重叠
- 可使用**适格之钥**更改天分位置，**能力砥石**提升至+10
- PVP 中天分和性格均保留生效

## 三、伤害系统

### 3.1 核心公式 ✅

```
伤害 = floor(
    (攻击方实际攻击力 / 防御方实际防御力)
    × (37/41)
    × 威力
    × 属性克制
    × 本系加成
    × 特性倍率
    × 其他倍率
    × (1 - 减伤%)
    × 连击数
)
```

### 3.2 关键特性

| 特性 | 值 |
|------|-----|
| 伤害波动 | **无**（完全确定，仅 floor 取整）✅ |
| 等级影响 | **无**（等级不参与伤害计算）✅ |
| 本系加成(STAB) | **1.25**（不是宝可梦的 1.5）✅ |
| 固定常数 | **37/41** ≈ 0.9024 ⭐ |
| 双克制 | 1+1+1 = **3倍** ✅ |
| 暴击 | **不存在**，所有伤害可精确计算 🔍 |

### 3.3 星陨伤害 ✅

```
星陨威力 = 层数² + 24 × 层数 - 24
星陨伤害 = floor((攻/防) × 37/41 × 星陨威力 × 幻系克制 × (1-减伤%))
```
- 幻系技能不触发星陨
- 星陨印记是负面印记

### 3.4 灼烧伤害 ⚠️

```
每层灼烧 = 敌方最大HP × [2%? 4%?]  ← 多源数据不一致
PVP 按实际血量计算（上限按 1000 血量）
回合中触发 = 真实伤害（不受属性克制）
回合结束触发 = 受属性克制影响
衰减 = 回合结束衰减一半层数（向上取整）
火系精灵免疫
```

> ⚠️ 每层伤害百分比：用户确认/BWIKI 攻略说 2%，网页搜索结果说 4%。需实测验证。

### 3.5 能力等级

**洛克王国：世界不存在能力等级（强化/弱化等级）系统。** ✅

网上流传的 `1+N×0.5` 或 `1+N×0.1` 公式均来自旧页游或其他游戏，不适用于本作。增益/减益全部通过**印记、特性、异常状态、技能效果**等机制实现。

## 五、魔力值系统 🔍

独立于精灵 HP 之外的**全局团队资源**：

| 项目 | 规则 |
|------|------|
| 初始值 | 双方各 **4 点** |
| 扣除 | 每阵亡一只精灵，扣 1 点 |

## 六、技能系统

### 6.1 分类
- 物理(172)、魔法(133)、变化(189) — 共 494 个 ⭐
- 伤害类型由技能分类决定，物攻/魔攻对应物防/魔防

### 6.2 三大技能类型的「应对」克制闭环 🔍

游戏核心是**攻击→状态→防御→攻击**的三角克制：

| 技能类型 | 克制对象 | 克制效果 |
|----------|----------|----------|
| **攻击型** | 状态型 | 1.5 倍伤害 + 附加效果（如打断） |
| **状态型** | 防御型 | 破防，可使目标昏迷、增加技能能耗等 |
| **防御型** | 攻击型 | 高额减伤 + 反制效果，成功后获得「先手+1」 |

**「应对」机制定义** 🔍：当技能指定的「应对」类型与对手当回合释放的技能类型匹配时，**本回合必定先释放应对技，再释放被应对的技能**。绝大多数应对技在应对成功时产生额外效果。

> 战术口诀：遇状态用攻击 → 1.5倍伤害加打断；遇防御用状态 → 破防加控制；遇攻击用防御 → 减伤抢下回合先手

### 6.3 技能标签机制 🔍

| 标签 | 说明 |
|------|------|
| **应对攻击** (48) | 被攻击时触发不同效果 |
| **应对防御** (26) | 防御时触发不同效果 |
| **先手** (9) | ±1，改变行动顺序；成功使用防御技格挡后可获得先手+1 |
| **蓄力** (8) | 本回合蓄力不释放，下回合再次选择该技能才正式释放（高风险高回报） |
| **脱离** (12) | 主动下场，触发入场效果 |
| **传动** (11) | 技能在 1-4 号位间每回合移动 |
| **迅捷** | 主动换精灵入场时，立刻自动释放该技能（不占用回合） |
| **折返** | 离开战场回背包，换一只非自己的精灵入场 |
| **连击** | 以相同威力造成 X 次伤害（每段均可触发吸血/印记） |
| **吸血** | 造成伤害的一部分用于回复自身生命值 |
| **迸发** | （精确触发条件待确认） |
| **巧变** | （技能转换规则待确认） |

### 6.4 技能标签联动 🔍

| 组合 | 战术价值 |
|------|----------|
| **折返 + 迅捷** | 折返换人 → 换上带迅捷技能的精灵 → 入场立刻释放，无缝衔接 |
| **连击 + 吸血** | 每段伤害均可触发吸血，回血效率翻倍 |
| **迅捷 + 连击/吸血** | 入场即发动连击或吸血，实现突袭或紧急回血 |

### 6.5 天气效果 ⚠️

| 天气 | 效果 | 持续 |
|------|------|------|
| 暴风雪 | 每回合为非冰系叠加1层冻结（每层=5%最大HP），HP% < 冻结层数时强制退场；冰系免疫 | 5~8回合 🔍 |
| 沙暴 | 地系技能能耗-2、地系伤害+15%、双防+10%；非免疫精灵每回合损失5%最大HP 🔍 | 8回合 |
| 雨天 | 水系技能威力 [提升75% ✅? / 提升50% 🔍?] | 8回合 |

> ⚠️ 天气数值差异：mechanics 原有数据（用户确认）说雨天+75%，搜索说+50%；沙暴原有数据说能耗减半，搜索说-2点。需实测验证。

### 6.6 天气通用规则

- **全场生效**：对敌我双方同时生效
- **持续时间**：**8 回合**后自动消退 ✅
- **覆盖机制**：天气只能被新天气覆盖，不能被"环境"类技能覆盖，反之亦然
- **PVE 特殊天气**：首领战可能锁定特殊天气（星云/陨石/迷雾等）

## 七、异常状态 ✅

| 状态 | 施加技能数 | 每层效果 | 衰减 | 触发时机 |
|------|:----------:|------|:----:|------|
| 灼烧 | 8 | **2%** HP 火伤 | ✅ 减半（向上取整） | 回合结束 |
| 中毒 | 17 | **3%** 最大HP 毒伤 | ❌ 不衰减 | 回合结束 |
| 冻结 | 12 | **5%** 最大HP，HP% < 冻结% → 直接力竭 | — | 实时判定 |
| 星陨 | 11 | 非幻系技能攻击时触发，消耗全部层数造成额外幻系伤害 | 一次性消耗 | 攻击时 |
| 萌化 | 9 | 退化到**进化链上一阶**，种族值同步降低 | — | 即时 |
| 寄生 | 1 | **6%** 最大HP 吸取（草系免疫） | — | 回合结束 |

### 异常状态细节

**冻结**：
- 替代旧版麻醉/冰冻/睡眠等传统硬控
- 每层冻结 5% 最大HP，血条上显示冻结标记
- 当精灵当前HP百分比 < 被冻结比例时 → 直接力竭
- 本质是血量阈值判定击杀，不是传统的跳过回合控制

**萌化**：
- 精灵变为进化链上一阶形态（如三阶→二阶）
- 种族值同步降为上一阶
- 若已是初始形态则无法萌化
- 萌系精灵萌化时可清除自身所有负面效果 🔍

**中毒 vs 灼烧**：
- 中毒稳定持续伤害（3%/层/回合），不衰减，适合长期消耗
- 灼烧单层伤害更高但会衰减，适合短期爆发

## 八、印记系统

### 8.1 核心规则 ✅

**每方最多同时存在 1 个正面印记 + 1 个负面印记**，新印记覆盖同类型旧印记。

- 印记**常驻战场**，不会随精灵下场而清除（区别于增益/减益）
- 正面印记和负面印记**互不影响**，各自独立遵守"最多1种"规则
- 增益/减益在精灵**下场后立即清除**

## 九、血脉系统 ✅

血脉的作用是**更改精灵的血脉属性**，从而改变可用的血脉技能。

### 9.1 血脉类型
- 每只精灵可更换血脉类型（18种属性各一种：火/水/草/光/地/翼/冰/虫/龙/电/幻/毒/恶/萌/幽灵/武/机械/普通）
- 更换血脉后获得该属性对应的血脉技能
- 不同精灵换相同血脉得到的技能组合不同
- 血脉技能池共 **81 个**独特技能

### 9.2 战前选择：进化之力 / 愿力冲击（整场比赛二选一）✅

对战前**整场比赛**选择携带其一：

| 名称 | 使用次数 | 冷却 | 效果 |
|------|:--------:|:----:|------|
| **进化之力** | **1 次** | 无冷却 | 对首领血脉精灵使用，本场战斗中进化，部分精灵激活远古血脉 |
